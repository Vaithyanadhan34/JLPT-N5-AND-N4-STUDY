HOW TO USE

A simple N5 → N4 study flow

  1. Finish N5 foundations first: common vocabulary, basic kanji and core grammar.
  2. Switch to N4 + N5 when you start N4.
  3. Open a card to see the reading above the kanji, meanings and examples.
  4. Use Mark as read and Know it to build browser-saved progress.
  5. Use Flashcards and Quiz to actively recall instead of only reading.
  6. Grammar Compare is for pairs or groups of 2–6 patterns.
